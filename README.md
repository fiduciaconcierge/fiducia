# Fiducia | Global Private Concierge

A luxury concierge web experience built with React, Vite, and Framer Motion.

## Live Site
https://fiduciaconcierge.github.io/fiducia/

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`

2. Run the app:
   `npm run dev`

## Deploy

`npm run build` then `npm run deploy`
